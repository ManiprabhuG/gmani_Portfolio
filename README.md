## 💡 About the Project

I built this portfolio from scratch using pure **HTML5**, **CSS3**, and **Vanilla JavaScript**. 

Rather than using heavy frameworks or complex build tools, I wanted to keep the site lightweight, fast-loading, and completely dependency-free for production.

### Highlights
- **Dark Theme with Custom Accents:** A dark obsidian color scheme (`#050507`) with glowing neon pink accents (`#FF2D78`).
- **Interactive UI Elements:** Subtle mouse-tracking glow follower on desktop, animated ambient background orbs, and smooth staggered scroll reveals via native `IntersectionObserver`.
- **Fully Responsive:** Adapts cleanly across mobile screens, tablets, and wide desktop monitors with a custom slide-out hamburger navigation.
- **Working Contact Form & Email Preview:**
  - Form validation for required fields.
  - Interactive preview modal displaying formatted email contents before submission.
  - Direct email delivery powered by EmailJS along with a backup webhook listener.
- **SEO Ready:** Includes structured data (`schema.org` JSON-LD), Open Graph metadata, and Twitter cards for better search engine discovery and social sharing.
- **Custom 404 Page:** Dedicated error page with playful floating animations and quick navigation back to home.
- **Time Calculation Utilities:** Includes `time_travel.js` and `style.js` scripts that calculate exact age milestones and seconds lived in word form.

## 🚀 Running Locally

You don't need to run `npm install` or configure any bundler.

1. **Clone the repo:**
   ```bash
   git clone https://github.com/ManiprabhuG/gmani_Portfolio.git
   cd gmani_Portfolio
   ```

2. **Open in browser:**
   - Simply double click `index.html`, or
   - Use VS Code with the **Live Server** extension, or
   - Run a quick local server with Python:
     ```bash
     python -m http.server 3000
     ```
     Then open `http://localhost:3000` in your browser.

3. **Running the Time Travel script (Optional):**
   ```bash
   node time_travel.js
   ```
